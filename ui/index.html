Troubleshooting

  • For Tile, increase Cell size by 1 px at a time or set Coarse center to 2×. A partial view of the screen is enough.
  • For QR, reduce Bytes per frame to 1,465, then reduce Frame rate to 24 fps if needed. Keep the entire QR code in view.
  • Rest the camera on a steady surface and allow a few seconds for it to focus.
  • Set the sending screen to maximum brightness.
